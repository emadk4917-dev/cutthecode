The setup prompt

Paste this into Claude Code.

You are setting up [TOOL, e.g. n8n] as a free replacement for [PAID APP] for me.
1. Find the official GitHub repo and its self-hosting / install guide. Tell me in 3 lines what it needs (server, Docker, domain) and the cheapest way to run it.
2. Ask me which option I want: on this computer, or on a small server I give you SSH access to.
3. Install it step by step. After each command, check the output; if something fails, fix it before moving on.
4. Secure it: create my admin login (I'll type the password myself), turn on HTTPS if it's on a server, and set up automatic backups.
5. Move my data across if the paid app can export it (show me how to export, then import it).
6. Finish with: the URL to open, how to update it later, and what it costs me per month (£).

Never paste passwords or API keys into chat; type them into the app itself.
